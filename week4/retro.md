### uv 환경
- pip, venv, requirements.txt 역할을 어느 정도 한 번에 처리해 주는 Python 패키지/환경 관리 도구
- 가상환경 관리 + 패키지 설치(pip 대체) + 파이썬 버전 관리 + 프로젝트 관리
- Rust 기반으로 기존 pip 대비 10~100배 속도

### scikit-learn
- sklearn.datasets: 사이킷런에서 제공하는 실습, 테스트용 데이터 세트 관리 모듈
- 머신러닝 모델을 만들고 테스트할 때 외부에서 데이터를 직접 수집하거나 가공하지 않고도, 함수 호출 한 번으로 정제된 데이터를 즉시 로드 가능
- make_moons()를 통해 일부러 선형으로 잘 안 나뉘는 데이터도 제작 가능
- classification_report()를 통해 분류 모델의 평가 지표 출력 가능 (Precision, Recall, F1-score, Support) 

### 소감
- 다음부터 코랩에서 해야겠다는 생각이 든다.
- uv를 쓸 때, IDE가 어떤 Python을 보고 있는지 확인하는 습관이 필요하다는 것을 알게 됐다.
- 전체적으로 이번 과제는 머신러닝을 "데이터 준비, 환경 관리, 모델 비교, 결과 확인"까지 하나의 흐름으로 보는 연습이 됐다. 
- 이번 과제에서는 실제 데이터를 찾지 않고 `sklearn.datasets`에서 가상 데이터를 만들었다. 굉장히 편하다. make_moons 이름이 좀 멋있다
- 2차원 가상 데이터에 노이즈를 추가하는 방식으로 Data augmentation을 실현하며, seed에 따라 정확성 향상률이 다르다는 것을 알았다.이를 통해 데이터 증강은 단순히 데이터를 많이 만드는 것이 아니라, 실제로 들어올 법한 현실적인 변형을 추가하는 과정에 가깝다는 점을 알게 되었다.
